# 🌿 Axis GC (Eliza Oliver) - Sistema de Gestão para Medicina Chinesa e Saúde Integrativa

O **Axis GC** é uma plataforma médica e clínica completa para gestão de **Medicina Tradicional Chinesa (MTC), Acupuntura, Terapias Integrativas e Saúde Geral**.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js `v18.x` ou superior
- Gerenciador `npm`

### Passos
1. **Instalar dependências**:
   ```bash
   npm install
   ```
2. **Configurar o arquivo `.env.local`** (Supabase e MercadoPago)
3. **Executar o ambiente de desenvolvimento**:
   ```bash
   npm run dev
   ```
4. **Compilar para produção**:
   ```bash
   npm run build
   ```
